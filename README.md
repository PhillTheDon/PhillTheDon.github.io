# Personal Portfolio

A static GitHub Pages portfolio site built with HTML and CSS.

## Before publishing

Replace these placeholders in `index.html`:

- `Your Name` and the email address
- `your-username`
- `your-linkedin-username`
- the CSC311 capstone repository URL and description
- the third project title, description, and repository URL

## Publish with GitHub Pages

Push this project to a GitHub repository, open **Settings > Pages**, select **Deploy from a branch**, choose the default branch and the repository root, and save. The site will be available at `https://your-username.github.io/portfolio-website/`.

For the GitHub profile portion of the assignment, add a professional photo and short bio, pin this portfolio plus two other strong public repositories, and add LinkedIn and other professional links to your profile. Submit the profile URL and the Pages URL to the LMS.
